# 02.3 — Tags page and header navigation

Status: done

## Description

Add a top-level way to browse all photos of a tag.

- Add header navigation `Albums | Tags` (leaving room for future `Map | Settings` siblings) in `web-nextjs/components/AppLayout/AppHeader.tsx`, mounted via `web-nextjs/app/(authenticated)/layout.tsx`.
- Add a **Tags page** that opens on `favorite` by default and shows a grid of all medias carrying that tag, across all albums, reusing the album media grid presentation (`AlbumMediaGrid/`).

Build against the pinned list-medias-by-tag REST contract in `specs/2026-11-media-tagging/design.md` ("Client/server interface"); mock the adapter so this story does not depend on the backend.

## Dependencies

None (contract mocked).

## Acceptance criteria

- Header shows `Albums | Tags`; current section is indicated; navigation works.
- The Tags page lists all medias tagged `favorite`, across albums, in a grid consistent with the album view.
- Empty state handled (no favourites yet).
- Covered by Storybook/visual and unit tests per the web testing strategy.

## Out of scope

- A tag switcher / choosing a tag other than `favorite` (later story).
- Applying or removing tags from this page.
- Real backend wiring (mock the adapter against the pinned contract).
