# 02.2 — Favourite star toggle on the album grid

Status: ready

## Description

Let an owner mark a media as a favourite directly from the album media grid, as the fastest possible single gesture.

A star overlay appears on each media (on hover, and always-on when favourited); clicking it toggles the `favorite` tag on that media. The state reflects the tags already attached to the media. The star is independent of any later tagging mode.

Build against the pinned REST contract in `specs/2026-11-media-tagging/design.md` ("Client/server interface" — add-tag / remove-tag, and the `tags` field on medias returned for an album). Mock the adapter so this story does not depend on the backend.

Relevant touchpoints: `web-nextjs/app/(authenticated)/albums/[ownerId]/[albumId]/_components/AlbumMediaGrid/` and `MediaThumbnail.tsx`; the web `Media` model and state in `web-nextjs/domains/catalog/language/catalog-state.ts`; the fetch adapter `web-nextjs/domains/catalog/adapters/api/FetchCatalogAdapter.ts`.

## Dependencies

None (contract mocked).

## Acceptance criteria

- Each media in the album grid shows a star; favourited medias show it filled/active.
- Clicking the star toggles `favorite` on that media and updates optimistically; failures revert the state.
- The web `Media` model carries its tags, populated from the album media load.
- Covered by Storybook/visual and unit tests per the web testing strategy.

## Out of scope

- The general (namespaced) tagging mode and tag picker.
- The Tags page and header navigation.
- Real backend wiring (mock the adapter against the pinned contract).
